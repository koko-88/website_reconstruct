## Responsibility

Inferred grouping: describe the bounded local fixture and its observable host experience, without proposing software service boundaries.

## Language

Declared vocabulary: reference-equivalent fixture, host dialog, source-declared mechanism, observed behaviour, target adaptation and allowed unknown.

## Boundaries

Declared: later target adaptation and distribution are separate phase decisions. Exact provider commerce and external page designs are excluded.

## External Relationships

Declared: host-side outbound link roles remain in scope; remote sites/providers are boundary destinations. No external integration or backend architecture is selected.
