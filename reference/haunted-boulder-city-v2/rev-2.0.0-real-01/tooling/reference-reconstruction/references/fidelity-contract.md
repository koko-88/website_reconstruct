# Fidelity / Scope Contract

Set the contract before interacting with the reference. Inventory newly discovered routes/states afterward without inventing prior agreement. Record revision, instruction/decision authority, intended source date/version, precedence, requested phase and access boundary.

| Class | Required decision |
| --- | --- |
| Exact reproduction | Concrete relationships/behaviors/values: layout, font metrics, crop, breakpoints, layers, navigation, motion or distinctive rendering. Give comparison environment and geometric/image/behavior/timing criteria. Exact is scoped, not universal pixel identity across OSs. |
| Adaptable content/data | Replaceable slots, text/images/counts/locales and domain actions. Separate invariant rules from content-driven geometry. Target mapping can remain pending during reference-only inspection. |
| Third-party replacement | Provider boundary, preserved host shell/interaction contract, replacement function/destination and allowed visual/behavior differences. Replaceable payment internals need not block host-shell fidelity; an exact selectable-date journey still requires evidence. |
| Excluded | Routes, states, environments or outcomes and user scope authority. Inaccessibility is not exclusion. |
| Allowed unknown | Uncertainty ID, unaffected obligations, maximum effect, bounded implementation rule/check, owner and reopen trigger. Backend internals/random frame phase/out-of-scope devices may be irrelevant; a missing core state cannot be waived by the inspector. |

Before inspection fill all five classes, even if “none established” or “pending, discovery only.” Environment ranges may be provisional. 1440x900, 1024x768, 768x1024, 390x844 are example samples, not discovered breakpoints or promised device equivalence.

Do not assume “clone” authorizes brand reuse or service replacement. Seek only missing consequential decisions; reuse existing instructions. Capture independent scope while affected decisions remain pending. Do not silently narrow scope to manufacture PASS.

Link contract ID -> coverage row -> evidence -> acceptance seed -> gate. Amend authority/version prospectively with a decision source. Later permissions/substitutions never change old facts or gates.
