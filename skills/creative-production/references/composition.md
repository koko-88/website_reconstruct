Discover actual paths; load only the specialist needed now. This skill coordinates intent and
acceptance rather than copying specialist API manuals. New consumers select required peers only.

When applying UI UX Pro Max, resolve its scripts against its actual installed root. Its design
system search is useful but its default html-tailwind stack does not override this React/Vite
consumer or a future project's stack. Use --persist only when the project's owning design artifact
needs it; do not create another MASTER authority over existing specs. Optional UI UX Designer
skills route by their actual entry point and do not implicitly select their external designer.

If a skill/tool is unavailable, say which function is missing, use an existing equivalent if
authorized, and verify its result. Do not copy full upstream kits or reinstall workstation tools.
For stopped Windows Blender/Polypane bridges reuse tooling/creative/start-workstation.ps1 with
a verified absolute executable, then re-probe. It preserves existing processes/scenes and does not
install or enable accounts. Polypane uses existing pane IDs; its Electron lacks Chrome new-context
APIs. MCP screenshots may require OS-temp then an authorized file copy into project artifacts.
Do not bypass service path protections. No connection can be inferred from configuration alone.
